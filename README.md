## 🚀 How to Use VBA Modules (`.bas`)

If you want to use any of the `.bas` files included in the `vba/` directory:

1. Open Microsoft Excel and press `ALT + F11` to open the VBA Editor.
2. In the menu, go to **File > Import File...** (or right-click your VBAProject and select **Import File...**).
3. Select the desired `.bas` file from the `vba/` folder.
4. Close the VBA editor and return to Excel.
5. Press `ALT + F8`, select the macro you want to run, and click **Run**.
